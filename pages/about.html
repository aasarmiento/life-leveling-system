THE REASON

Why Questify

Most effort disappears at the end of the day. Meetings, pages, walks: they happened, then they vanished. This site names the work you already do so you can see it add up.

PATH 01

Work

Focus time, meetings, and the admin that never makes it onto a to-do list. Log it and it counts.

EXAMPLEInbox zero+10 XP
PATH 02

Learning

Classes, reading, practice, and side projects. Progress here is slow, so it helps to watch it add up.

EXAMPLERead one chapter+20 XP
PATH 03

Health

Workouts, walks, sleep, and rest. Small habits matter most when you keep them up.

EXAMPLE45-min run+30 XP

The quest loop

Four steps, every day
  1. 01

    Add a quest

    Name it, pick a path, and set a priority.

  2. 02

    Do it in real life

    The site doesn’t watch you. You go do the thing.

  3. 03

    Mark it done

    Confirm it’s done and the XP is yours.

    +10 / +20 / +30 XP
  4. 04

    Level up

    The bar fills. Every 125 XP, your level goes up.

    Level 12108 / 125 XP

Then pick your next quest and do it again

GOOD TO KNOW

What XP is not

XP isn’t a score to judge you by. It’s proof of the work you already did.

XP IS

Not a grade

It measures effort, not talent. A hard day of trying still counts.

XP IS

Not a race

No rankings against other people. Your only rival is yesterday’s you.

XP IS

Not a currency

There’s nothing to spend it on. It’s a record of how far you’ve come.

XP ISthe effort you already put in, made visible.

ORIGIN

How Questify started

Questify began in a Web Systems and Technology class, when five of us kept finishing work that never seemed to count for anything beyond the deadline. Study blocks, commits, workouts, and long nights of documentation disappeared the moment they were done.

We wanted a simple way to turn that effort into something we could see, so we built a small system that logs real daily work as XP and levels. What started as a course project became Questify: a tool for making invisible progress visible, one log at a time.

Built for Web Systems and Technology

Plain HTML, CSS and JavaScript. No backend. Your data stays in your browser.

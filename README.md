# Questify

## Conquer your goals, one quest at a time.

Questify is a gamified personal progress web app that turns real-life effort (Work, Growth, and Health) into XP and levels. It helps users track their progress and stay motivated by making daily achievements visible and rewarding.

## Concept

A simple browser-based dashboard allows users to create and complete tasks, earn XP based on difficulty, level up, and track progress, while also viewing personal analytics and activity history. It is inspired by Codédex, Habitica, and the Solo Leveling System.

## Features
* User Authentication
* Dashboard with current level, XP progress bar, and today's tasks
* Full Task Manager (Create, Read, Update, Delete)
* XP and Leveling system
* Activity history and basic analytics
* Clean and responsive design

## Tech Stack
The tech stack consists of HTML, CSS, and Vanilla JavaScript for the frontend, and Node.js with Express.js for the backend.
